# 星轨抽卡实验室

一个轻量的网页版 AI 抽卡模拟器，用来体验稀有度、概率、保底和抽卡记录。

## 功能

- 单抽与十连抽
- 晨昏棱镜与霜火边界两套卡池，可随时切换
- 星轨图鉴与 SSR / SR / R 分类筛选
- SSR / SR / R 三档稀有度
- SSR 80 抽保底，两个卡池分别记录保底进度，切换卡池不会互相影响
- 当前卡池 SSR 为 55% UP、45% 常驻，歪不会抽到另一卡池的 UP
- 十连至少获得 1 张 SR
- 抽卡结果动画与结果弹窗
- 本地历史记录
- 本地保存保底进度、抽卡次数和星尘余额
- 可补充模拟用星尘，不涉及真实消费

## 试玩

打开 `dist/index.html` 即可使用。

如果使用本地静态服务器：

```powershell
python -m http.server 4173 --directory dist
```

然后访问：<http://127.0.0.1:4173/>

## 项目结构

```text
dist/
  index.html       # 完整的单页应用
.openai/
  hosting.json     # Sites 托管配置
```

所有抽卡状态都保存在浏览器本地，不会上传抽卡记录，也不涉及真实货币或奖品。
